☁️Google Drive yedeği
⚠️ Bu sayfa şu an bir web adresinde (https) açık değil: yerel dosya ya da önizleme penceresi olarak çalışıyor (kaynak: null). Google ile oturum açma bu şekilde çalışmaz. Sayfayı önce bir web adresine koyun (örn. GitHub Pages) ve oradan açın; adımlar aşağıdaki kılavuzda.
Kurulum: Google istemci kimliği (yalnızca bir kez)
  1. Sayfayı https bir adreste açın (ör. GitHub Pages). Bu adım olmadan Google giriş yapmaz.
  2. Google Cloud Console'da yeni bir proje oluşturun.
  3. API'ler ve Hizmetler → Kitaplık'ta Google Drive API'yi bulup Etkinleştir'e basın.
  4. Google Auth platform bölümünde: Branding'de uygulama adı "My Library" ve destek e-postası girin; Audience'ta kullanıcı türü External (Harici) seçin ve Test users → Add users ile kendi Gmail adresinizi ekleyip kaydedin.
  5. Google Auth platform → Clients → Create client: uygulama türü Web application. Authorized JavaScript origins → Add URI ile şu adresi ekleyin (https olmalı, sonunda yol olmamalı):
  6. Oluşan Client ID'yi aşağıya yapıştırıp Google ile bağlan'a basın. İlk girişte "Google bu uygulamayı doğrulamadı" uyarısı normaldir: Advanced → Go to My Library deyin.
Uygulama yalnızca kendi oluşturduğu my-library-yedek.json dosyasına erişir (drive.file izni); Drive'ınızdaki başka dosyaları göremez.
